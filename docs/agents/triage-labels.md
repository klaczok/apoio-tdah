# Labels de triagem

As skills usam cinco funções canônicas de triagem. Esta tabela mapeia essas funções para as labels usadas neste repositório.

| Função canônica | Label local | Significado |
| --- | --- | --- |
| `needs-triage` | `pendente-triagem` | Precisa ser avaliado pelo mantenedor |
| `needs-info` | `precisa-informacoes` | Aguarda mais informações |
| `ready-for-agent` | `pronto-para-agente` | Está completamente especificado e pronto para um agente |
| `ready-for-human` | `pronto-para-humano` | Requer implementação humana |
| `wontfix` | `nao-sera-feito` | Não será implementado |

Quando uma skill mencionar uma função canônica, use a label local correspondente nesta tabela.
